This project is a corporate prototype designed to streamline the receiving process for products and pallets. 
By utilizing barcode scanning, the system tracks essential data such as batch numbers and, most importantly, expiration dates. 
The platform stores this information and features a management dashboard with intuitive charts that monitor shelf life in real-time.
Additionally, it issues automated alerts to the client, offering a significantly more organized and efficient solution compared to the manual logging of items during reception or shelf stocking.

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
